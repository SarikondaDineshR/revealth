# Revealth Demo Storytelling Script

## Setup

Open the Company Command Center for a fresh smoke workspace:

`http://localhost:3000/workspaces/<workspaceId>/company`

Demo scenario: Harbor & Pine Realty wants a real estate CRM for contacts, buyer and seller leads, showing notes, reminders, pipeline stages, and broker reporting.

## Talk Track

1. Start with the headline.
   Revealth is not pretending to be a chatbot. It is showing an AI software company working under governance.

2. Point to Project Journey.
   The project moves from idea, to planning, to team assignment, to simulated work, then stops at approvals.

3. Point to AI Team.
   The CEO keeps scope tight, PM organizes requirements, Design thinks about workflow, Engineering breaks down work, QA looks for risk, and Sales/Customer Success prepare client-safe updates.

4. Point to Current Work.
   The system distributes work across activated agents, but it does not execute code or mutate the repository.

5. Point to Team Discussion.
   This is the internal operating rhythm: updates, decisions, handoffs, blockers, and reviews.

6. Point to Client Updates.
   Client-facing language is simulated and governed. Nothing is sent externally.

7. Point to Approvals Needed.
   The human owner remains the authority boundary. The system waits instead of acting when approval is needed.

8. End with Next Safe Step.
   Revealth always answers: what is safe to do next, what is blocked, and why.

## Demo Invariant

No external communication. No live execution. No branches. No pull requests. No calls. No meetings. The demo shows controlled autonomous coordination, not uncontrolled autonomy.
