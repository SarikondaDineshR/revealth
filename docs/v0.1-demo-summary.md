# Revealth v0.1 Demo Summary

## Positioning

Revealth is an autonomous AI software company operating system. v0.1 demonstrates the governed control plane required before any autonomous coding or production operation is allowed.

The demo proves that Revealth can transform an idea into structured SDLC planning artifacts while preserving human approval, artifact lineage, auditability, and execution safety boundaries.

## What v0.1 Demonstrates

The v0.1 demo covers:

- workspace creation
- intake workflow execution
- `project_brief` generation
- approval-gated SDLC planning
- approval-gated task generation
- approval-gated GitHub issue batch generation
- dry-run GitHub issue record creation
- Codex task packet generation
- Git execution plan generation
- Codex execution contract generation
- queued execution run creation
- dry-run execution lifecycle
- control-plane aggregation and dashboard rendering

End-to-end governed chain:

```text
idea
  -> project_brief
  -> sdlc_plan
  -> task_batch
  -> github_issue_batch
  -> codex_task_packet_batch
  -> git_execution_plan
  -> codex_execution_contract
  -> codex_execution_run
```

## Safety Boundaries

v0.1 remains human-governed:

- every workflow output becomes a structured artifact
- every critical transition requires approval
- every side-effect attempt is audit logged
- GitHub issue creation defaults to dry-run
- Codex execution defaults to disabled
- dry-run execution writes logs and metadata only
- executor workspace preparation writes manifest metadata only
- live execution is explicitly not implemented

## What Is Not Implemented

Revealth v0.1 intentionally does not:

- execute live code changes
- create Git branches
- create pull requests
- deploy software
- run production automation
- run autonomous billing or sales
- mutate repository files from the executor
- bypass human approval gates

## Demo Narrative

The clean story for another technical person:

1. Revealth starts as a governance-first AI company OS, not an agent toy.
2. The founder provides a software idea.
3. Temporal runs durable workflows that generate structured artifacts.
4. The human owner approves each critical transition.
5. Artifact lineage records the upstream artifact, workflow run, approval, prompt version, and model context.
6. External effects are dry-run protected.
7. Codex execution is represented by contracts and tracked runs, but live repository mutation is blocked.
8. The control plane makes readiness and auditability visible before autonomy expands.
