## Current Capabilities

- Workspace creation.
- Intake workflow execution.
- Governed artifact chain from project brief through execution run.
- Human approval gates.
- Artifact lineage.
- Audit logging.
- GitHub issue dry-run records.
- Codex task packet generation.
- Git execution plan generation.
- Codex execution contract generation.
- Dry-run execution run lifecycle.
- Control-plane dashboard for workflow, artifact, approval, audit, executor, and readiness state.

## Known Limitations

- Docker/buildx health can still block local container rebuilds on some machines.
- Smoke test assumes the local stack is already running and configured for dry-run execution.
- Demo data is safe synthetic data only.
- GitHub writes remain dry-run unless explicitly configured.
- Branch preparation is planning-only.

## Safety Guarantees

- No live Codex execution.
- No repository file mutation by the executor.
- No automatic branch creation.
- No automatic pull request creation.
- No production deployment.
- No real password or secret storage in demo flows.
- `.env` and `.revealth/` remain ignored.
- Approval gates remain required for governed transitions.
