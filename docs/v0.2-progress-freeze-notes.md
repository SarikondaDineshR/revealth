# Revealth v0.2 Progress Freeze Notes

## Scope

v0.2 progress currently covers Milestones 1-3 only. No live execution has been enabled.

## Milestone 1: Codespaces-First Reliability

- Added `corepack pnpm demo:doctor`.
- Improved `demo:bootstrap` to validate environment health before builds.
- Added fast failure for Docker, Compose, and buildx timeouts.
- Enforced safe demo defaults for dry-run GitHub and dry-run Codex execution.
- Updated Codespaces bootstrap guidance.

## Milestone 2: Control-Plane Usability

- Added Demo Status summary.
- Added Readiness Summary messaging.
- Added Approval Queue section.
- Added Execution Run Inspection section.
- Added audit timeline filter chips.
- Expanded UI helper/render tests.

## Milestone 3: Future Live-Execution Safety

- Strengthened path and command validation.
- Rejected wildcard allowed-file scopes.
- Rejected shell control operators in execution commands.
- Added immutable contract snapshot verification.
- Added executor manifest integrity verification.
- Persisted preflight summaries into execution run logs.
- Added live execution approval checklist.

## Current Guarantees

- v0.1 smoke path remains preserved.
- GitHub issue creation remains dry-run by default.
- Live Codex execution remains blocked.
- Executor does not mutate repository files.
- No branch or PR creation is implemented.
- Approval gates and audit logging remain required.

## Current Limitations

- Docker/buildx health can still block local container rebuilds.
- Demo smoke requires running local services.
- Control-plane filters are visual summaries, not interactive query controls.
- Live execution readiness is preparatory only.

## Known Operational Risks

- Docker Desktop or Codespaces Docker may hang before `loading Dockerfile`.
- Dirty worktrees can block readiness checks.
- Misconfigured `.env` can block demo smoke.
- Future live execution needs a separate approval and isolation design pass.

## Demo Command

```powershell
corepack pnpm demo:smoke
```

## Intentionally Blocked

- Live code execution.
- Automatic branch creation.
- Automatic pull request creation.
- Production deployment.
- Customer-facing automation.
- Secret access or real password storage in demo flows.
