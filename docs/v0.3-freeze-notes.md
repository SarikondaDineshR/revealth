# v0.3 Workforce Simulation Freeze

Status: freeze checkpoint for governed AI workforce planning and simulated coordination.

## Purpose

v0.3 extends Revealth from governed planning into visible AI workforce coordination while keeping execution non-live and owner-governed.

## Added

- Workforce scaling recommendations from approved `task_batch` artifacts.
- `workforce_scaling_plan` artifacts with complexity, role needs, bottlenecks, and summary.
- Approval-gated workforce activation from approved scaling plans.
- Idempotent activation that creates additional agent assignments without duplication.
- Simulated work dispatch across activated agents.
- Persistent dispatch records with task, agent, reason, complexity, status, and timestamps.
- Simulated progress updates and handoffs in the agent communication feed.
- Control Plane sections for recommended scaling, activated team, live dispatch, current activity, and handoffs.

## Current Guarantees

- No live code execution.
- No branch creation.
- No pull request creation.
- No phone or meeting agents.
- No autonomous repo mutation.
- Workforce activation requires an approved `workforce_scaling_plan`.
- Dispatch requires an approved `task_batch` and activated workforce.
- Dispatch actions, handoffs, and activation events are audited.
- Demo smoke covers scaling, activation, dispatch, and control-plane visibility.

## Current Limitations

- Dispatch is deterministic simulation, not autonomous execution.
- Agent progress messages are generated from rules, not live model reasoning.
- Workforce sizing is heuristic and not yet based on historical throughput.
- Dispatch records do not yet support reassignment or owner-driven prioritization.
- UI is observational; it does not yet provide dispatch controls.

## Next Recommended Milestone

Add owner-reviewed agent work packets: structured non-executing work briefs per dispatched task, with approval gates before any future live agent action.
