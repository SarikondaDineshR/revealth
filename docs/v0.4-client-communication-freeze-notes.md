# Revealth v0.4 Milestone 1 Freeze Notes

Milestone: Client Communication Foundation

Status: freeze-ready after validation

What was added:
- Client profiles for leads, prospects, customers, and inactive contacts.
- Lead/opportunity records tied to workspace client profiles.
- Simulated client conversation records with internal and client-visible visibility.
- Meeting request records with consent tracking and external joining disabled.
- Approval-gated `client_communication_script` artifacts.
- API routes for clients, leads, client conversations, meeting requests, and script generation.
- Audit events for client, lead, conversation, meeting request, and script creation.
- Control Plane sections for Client Pipeline, Lead Discovery, Client Communication Feed, Meeting Requests, and Sales/Support Script Drafts.
- Demo smoke coverage for the governed client communication substrate.

Safety guarantees:
- No external email, SMS, customer message, phone call, or meeting join is sent.
- `externalJoinEnabled` remains false for meeting requests.
- Sales/support scripts are drafts and require owner approval.
- Client-visible records are stored inside Revealth only.
- All client communication foundation actions write audit evidence.
- Live code execution remains disabled and unrelated to this milestone.

Current limitations:
- Client communication is simulation-only.
- No external communication provider is connected.
- No autonomous outreach exists.
- Meeting requests are internal planning records only.
- Script approval does not yet unlock any outbound side effect.

- Control Plane: `http://localhost:3000/workspaces/6f296155-9de8-4a72-9a67-60ffc31b874b/control-plane`

Next recommended milestone:
- External Communication Policy Gate.
- Define consent, approval, visibility, recipient, channel, and audit requirements before any real outbound communication is implemented.

Intentionally blocked:
- Phone calls.
- Zoom or Google Meet joining.
- External email/SMS/customer communication.
- Autonomous sales outreach.
- Live code execution.
- Branch or PR creation.
