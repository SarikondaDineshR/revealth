# Revealth v0.4 Milestone 3 Freeze Notes

Milestone: Communication Draft Generation

Status: freeze-ready after validation

Communication draft behavior:
- Added `communication_drafts` records.
- Added draft routes:
  `POST /workspaces/:workspaceId/client-communication/drafts`
  `GET /workspaces/:workspaceId/client-communication/drafts`
- Supports internal draft channels:
  `email_draft`, `meeting_draft`, `voice_draft`
- Drafts are generated from an existing client profile, optional lead, and approved communication script.
- Draft body explicitly states that no external message, meeting, call, SMS, or calendar event occurred.
- Control Plane now shows Communication Drafts Awaiting Approval.

Approval requirement:
- Draft generation requires an approved `client_communication_script`.
- Drafts are created as `pending_approval`.
- Drafts remain internal until owner approval.
- No draft approval route unlocks external sending yet.

Policy evidence storage:
- Draft generation evaluates the external communication policy.
- The full policy evaluation result is stored on `policyEvaluationJson`.
- Audit events are written for:
  `communication_draft.policy_checked`
  `communication_draft.generated`
  `communication_draft.approval_required`

Safety guarantees:
- No email is sent.
- No SMS is sent.
- No phone call is placed.
- No Zoom or Google Meet session is joined.
- No calendar event is scheduled.
- No autonomous outreach exists.
- Live code execution remains disabled and unrelated to this milestone.

Current limitations:
- Drafts can be generated and inspected, but not approved through a dedicated draft route yet.
- Policy approval and consent are still represented as stored state, not outbound authorization.
- Draft content is deterministic starter copy.
- No external communication provider is connected.
