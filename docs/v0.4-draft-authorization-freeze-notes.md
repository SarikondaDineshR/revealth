# Revealth v0.4 Draft Authorization Freeze Notes

## Purpose

Freeze v0.4 Milestone 4: approved communication drafts can now produce outbound authorization readiness records without enabling any external communication.

## Draft Approval Behavior

- Communication drafts support owner decisions: approve, reject, and request revision.
- Approved drafts move to `approved`.
- Rejected drafts move to `rejected`.
- Revision-requested drafts return to `draft` for internal rework.
- Draft decisions write audit events for approval, rejection, or revision request.

## Outbound Authorization Behavior

- Approving a draft creates an outbound authorization record with status `authorized_draft_only`.
- Rejecting or requesting revision creates a blocked outbound authorization record.
- Authorization records store the channel, consent state, owner approval id, and policy evaluation snapshot.
- `externalSendEnabled` is always `false`.
- The control plane shows outbound authorization readiness.

## Safety Guarantees

- No email sending exists.
- No SMS exists.
- No phone calls exist.
- No Zoom or Google Meet joining exists.
- No calendar scheduling exists.
- No autonomous outreach exists.
- Draft approval authorizes readiness only, not delivery.
- External-send capability remains intentionally blocked.

## Current Limitations

- Outbound authorization records are readiness evidence, not send permissions.
- Consent and policy state are captured for review but do not trigger external action.
- Revision handling resets draft status but does not yet create a revised draft workflow.
- No external provider integrations are connected.

## Smoke Workspace

- Latest validated smoke workspace: populated during freeze validation.
- Control plane path: `/workspaces/<workspaceId>/control-plane`.

Build a governed outbound-review package that summarizes approved drafts, policy blockers, consent requirements, and explicit human next steps while still keeping all external communication disabled.
