# Revealth v0.4 Milestone 2 Freeze Notes

Milestone: External Communication Policy Gate

Status: freeze-ready after validation

Policy gate behavior:
- Added `external_communication_policies` records.
- Added policy evaluation route:
  `POST /workspaces/:workspaceId/client-communication/policy/evaluate`
- Supported channel intents:
  `simulated_only`, `email_draft`, `meeting_draft`, `voice_draft`
- Supported consent states:
  `unknown`, `required`, `granted`, `revoked`
- Evaluation returns:
  `allowed`, `blockers`, `requiredApprovals`, `requiredConsent`, and `nextSafeAction`
- Control Plane now shows External Communication Readiness.

Default blocking behavior:
- External communication is blocked by default.
- Policy evaluation creates a blocked default policy if none exists.
- `email_draft`, `meeting_draft`, and `voice_draft` require granted consent.
- Approved communication script is required before future external action.
- Client and lead approval are required before future external action.
- Owner approval and audit evidence remain required.

Consent requirements:
- `unknown`, `required`, and `revoked` block external channels.
- Only `granted` can satisfy external-channel consent checks.
- Consent state is stored but no external communication is unlocked yet.

Safety guarantees:
- No email is sent.
- No SMS is sent.
- No phone call is placed.
- No Zoom or Google Meet session is joined.
- No autonomous outreach exists.
- Policy evaluation writes audit evidence.
- Live code execution remains disabled and unrelated to this milestone.

Current limitations:
- There is not yet an approval workflow to mark client/lead/policy readiness approved.
- Policy records are evaluated and displayed, but do not trigger outbound actions.
- Draft generation for specific email or meeting content is not implemented yet.
- Consent capture is represented as state only.
