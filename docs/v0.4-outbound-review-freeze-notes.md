# Revealth v0.4 Outbound Review Package Freeze Notes

## Purpose

Freeze v0.4 Milestone 5: approved communication drafts can now be assembled into governed outbound review packages for human review.

## Review Package Behavior

- Outbound review packages require an approved communication draft.
- They require a matching `authorized_draft_only` outbound authorization.
- Each package summarizes the approved draft, authorization state, policy evidence, consent state, blockers, required human action, and next safe step.
- Packages are idempotent per workspace and outbound authorization.
- The control plane shows `Outbound Review Package` readiness.
- Audit events record package generation requests, generated packages, and skipped duplicate generation.

## Safety Guarantees

- No email sending exists.
- No SMS exists.
- No phone calls exist.
- No Zoom or Google Meet joining exists.
- No calendar scheduling exists.
- No autonomous outreach exists.
- `externalSendEnabled` remains `false`.
- Review packages prepare human decision evidence only.

## Current Limitations

- Packages do not grant permission to send externally.
- Consent remains evidence-only until a future policy milestone.
- No external provider integrations are connected.
- No delivery workflow, scheduling workflow, calling workflow, or meeting workflow exists.

## Smoke Workspace

- Latest validated smoke workspace: populated during freeze validation.
- Control plane path: `/workspaces/<workspaceId>/control-plane`.

## Next Recommended Milestone

Create an explicit external communication operator checklist that reviews package evidence, consent, policy blockers, and required approvals while still keeping external delivery disabled.
